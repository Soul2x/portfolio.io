## Ⅳ. Design System & Aesthetic Vibe

This repository is built following the **Atelier Zero** design manifest—a tactile, high-craft editorial design system combining vintage typography with modern fluid micro-interactions.

### 🎨 Color Tokens & Palette

| Token Name | Hex Code | Visual Swatch | Purpose |
| :--- | :--- | :--- | :--- |
| `--paper` | `#efe7d2` | `██████` | Warm tactile paper background |
| `--ink` | `#15140f` | `██████` | Deep high-contrast editorial text |
| `--coral` | `#ed6f5c` | `██████` | Primary accent, status pulses & highlights |
| `--mustard` | `#e9b94a` | `██████` | Secondary accent & stat badges |
| `--olive` | `#6e7448` | `██████` | Vintage craft borders & subtle labels |
| `--bone` | `#f7f1de` | `██████` | Surface elevation cards & panels |

### ✒️ Typography Hierarchy

- **Display & Headings**: `Playfair Display` (Classic serif elegance)
- **Interface & Subtitles**: `Inter Tight` & `Inter` (Clean geometric sans-serif)
- **Code & Technical Annotations**: `JetBrains Mono` (Precision monospace)

### ✨ Visual Details & Craft
- **Paper Noise Texture**: Custom SVG noise filter overlay creating a tactile feel.
- **Fixed Side Rails**: Rotated coordinate & branding text along viewport edges.
- **Ticker Marquee**: Continuous smooth marquee displaying core skills & credentials.
- **Fluid Micro-Animations**: IntersectionObserver-driven scroll reveals (`data-reveal`).
