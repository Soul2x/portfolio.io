DeskPet — Interactive Desktop Companion App

A delightful desktop pet companion application featuring interactive state animations, hunger/happiness meters, customizable activities, and desktop widget UI built with React, Node.js, and Vite.

React Vite Node.js Desktop Shell CSS Animations State Mechanics

01 How I Built It — Architecture & Workflow

I designed DeskPet to bring a touch of nostalgia and interactive fun to everyday desktop work environments. Using React for component state management and Vite for rapid asset bundling, the app is structured around three main systems:

  • Virtual Pet State Machine: A finite state machine managing happiness, hunger, energy, and cleanliness levels that decay over real-time intervals.
  • Interactive Activity Controller: Action triggers (`Feed`, `Play`, `Sleep`, `Clean`) that update pet states, trigger custom sprite animations, and unlock achievement badges.
  • Desktop Overlay UI: Floating, frameless widget window layout with local storage state persistence so your pet's mood and stats carry over across app sessions.

02 Hurdles & Technical Complications Faced

⚠️ Hurdle 1: High CPU Usage from Idle Animation Intervals

Initial implementations relied on JavaScript setInterval() timers running every 100ms to drive pet movement and idle sprite frames, causing unexpected CPU usage when left open in the background.

⚠️ Hurdle 2: Pet Stat Decay Accumulation while Offline

When the user closed the application and reopened it hours later, stats either didn't decay at all or decayed instantly to 0%, causing negative state overflows and immediate "sad pet" states.

⚠️ Hurdle 3: Transparent Window Dragging & Click-Through

Creating a floating desktop companion required supporting drag-and-drop window positioning without intercepting clicks meant for underlying desktop icons.

03 Solutions & Engineering Takeaways

💡 Solution 1: CSS Hardware-Accelerated Animations & `requestAnimationFrame`

Replaced JavaScript position timers with hardware-accelerated CSS keyframe transforms for sprite loops and `requestAnimationFrame()` for idle wandering, reducing idle CPU utilization to under 1%.

💡 Solution 2: Elapsed Time Math & Clamped State Decays

Stored ISO timestamps in `localStorage` on session unload. On app launch, the system calculates `currentTime - lastClosedTime` and applies a linear decay formula clamped between 0% and 100%, producing realistic offline pet state progression.

💡 Solution 3: Frameless Window Drag Region Mapping

Configured CSS `-webkit-app-region: drag` on the pet container while keeping interactive action buttons `-webkit-app-region: no-drag`, enabling smooth window moving with crisp button responsiveness.
