Typing Test — Interactive Speed & Accuracy Web App

A high-performance React application designed for testing typing speed (WPM), accuracy percentages, character error breakdowns, and real-time keystroke speed curves built with React, Node.js, and Vite.

React Vite Node.js JavaScript (ES6+) State Management UI/UX Engineering

01 How I Built It — Architecture & Workflow

I set out to build a clean, minimalist Typing Test application similar to Monkeytype, focusing on zero latency, precise millisecond-level timing, and zero layout shift during fast typing. Built on top of Vite + React, the architecture consists of three main engine layers:

  • Keystroke Listener Engine: Global keyboard event handling that intercepts keypresses, backspaces, spaces, and modifiers while preventing default page scrolling.
  • Dynamic Word Stream Renderer: A memoized React component system that renders active, typed, correctly matching, and mistyped characters with custom CSS highlight states.
  • Real-Time Analytics & WPM Calculator: Live calculation of Gross WPM, Net WPM, raw accuracy percentage, and typing speed curves computed per second.

02 Hurdles & Technical Complications Faced

⚠️ Hurdle 1: Input Latency & Micro-Stutters at High Typing Speeds

When typing rapidly (80+ WPM), updating React state on every single keypress caused component re-renders across the entire DOM tree, resulting in subtle cursor lag and dropped keystrokes.

⚠️ Hurdle 2: Accurate WPM & Timer Calculations on Tab Blur

Standard JavaScript setInterval() timers drift when the browser tab loses focus or when background throttling occurs. This resulted in inflated or corrupted WPM numbers if the user switched tabs during a test.

⚠️ Hurdle 3: Backspace & Word Index Edge Cases

Handling backspace across multi-line text blocks required complex state tracking for word boundaries, character indices, and extra mistyped characters inserted beyond word lengths.

03 Solutions & Engineering Takeaways

💡 Solution 1: Ref-Based Keystroke Buffering & `React.memo`

I separated mutable input tracking into React `useRef` buffers and wrapped individual word tokens in `React.memo()`. Only the currently active word and previous word re-render on keypress, keeping DOM updates locked at a silky 60fps.

💡 Solution 2: High-Precision Timestamp Drift Correction

Replaced basic interval counting with high-resolution `performance.now()` timestamp deltas. The elapsed time is computed directly against true wall-clock time, ensuring accurate WPM figures regardless of browser tab focus or throttling.

💡 Solution 3: Immutable Character State Array

Designed a flat, immutable state structure representing character states (`correct`, `incorrect`, `extra`, `untyped`). Backspacing simply pops or mutates the specific index pointers cleanly without triggering cascading array reshuffles.
